# Project documents

This folder holds everything the FYP guideline asks for besides code. Folders
are numbered by phase so the order matches the FYP I document (Chapters 1 to 4).

| Folder | What goes here | Guideline sections |
|---|---|---|
| `00-guidelines/` | The department guideline (Oct 2026, v2.0). Read it, don't edit it. | All |
| `01-proposal/` | Approved FYP proposal and technical-writing proposal (PDF), Gantt chart, the earlier Markdown draft | 4 |
| `02-literature-review/` | Reading matrix, comparison table, verified IEEE references, Chapter 2 draft | 5.4, 5.5, 11.11 |
| `03-methodology/` | Chapter 3 draft: method, tools, data, work plan, risk management | 6, 9.1-9.3 |
| `04-requirements-and-design/` | Fact finding (questionnaires, interviews), SRS, architecture, UML diagrams, Chapter 4 draft | 7, 9.2 |
| `fyp1-document/` | Front matter, Chapter 1, and the assembled FYP I document (DOCX + PDF) | 11 |
| `project-management/` | Weekly logbook, risk register, traceability matrix, meeting minutes, change log | 6.2, 6.3, 10.6, 13, 4.6 |
| `compliance/` | AI-use disclosure, ethical screening checklist, individual contribution statements | 14, 15 |
| `technical-report/` | CoSc4511 technical report (CRNN+CTC vs TrOCR) | separate course |

- [ ] Risk register, reviewed with the advisor monthly
- [ ] Traceability matrix started (objectives → requirements → design)
- [ ] Ethical screening checklist (Appendix M), with written approval before any questionnaire or interview

- [ ] Individual contribution statement for each member (Appendix G)
