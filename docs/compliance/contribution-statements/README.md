# Individual contribution statements (Appendix G)

One file per member: `eyob.md`, `hallelujah.md`, `leawi.md`, `maryamawit.md`.
Roles are declared in the proposal and recorded again here (Section 14.2).
Each member must hold primary technical responsibility for at least one major
component. These statements, the logbook and the commit history feed the
Individual Contribution Factor (Section 17.7), which scales each member's share
of the examiner mark.

Every member must also be able to explain the **whole** system, not only their
own part (Section 14.3).
