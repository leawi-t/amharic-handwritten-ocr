# Reading matrix

One row per source. Fill in the columns **after reading the source**, not from
its abstract or an AI summary. "Verified" means you checked the full citation
details (authors, title, venue, year, pages, DOI) against the actual paper.

Target: at least 15 credible sources across all themes (guideline 5.5), about
4 to 5 per theme. Journal and conference papers first, web sources only as support.

Each theme: start with the general work, then narrow down to Amharic or other
low-resource languages. End with 1 to 2 paragraphs on what your sources show
together (agreement, disagreement, what is missing), in `notes/<theme>-synthesis.md`.

| Theme | Owner |
|---|---|
| T1 Sequence and Transformer recognition models (CTC, CRNN, TrOCR) | Hallelujah |
| T2 Post-OCR error correction | Leawi |
| T3 Existing OCR apps and mobile OCR | Maryamawit |
| T4 Amharic / Ethiopic OCR studies and datasets | Eyob |

Column guide: **Problem**: what task the source addresses. **Method**: model
or technique. **Data**: dataset, size, language/script. **Metrics**: how
results were measured. **Key result**: main finding with numbers.
**Weaknesses**: small data, weak evaluation, not comparable, outdated, etc.
