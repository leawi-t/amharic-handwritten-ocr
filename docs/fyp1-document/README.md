## Formatting (Section 11)

| Item | Specification |
|---|---|
| Paper | A4 |
| Body text | Times New Roman 12 pt, justified, 1.5 line spacing, 6 pt after each paragraph, no first-line indent, no blank lines between paragraphs |
| Chapter title | Times New Roman 14 pt, bold, UPPER CASE, centred, each chapter on a new page |
| Second-order heading | 13 pt bold |
| Third-order heading | 12 pt bold (no deeper headings) |
| Captions | 11 pt, label in bold. Tables: caption above. Figures: caption below. Numbered by chapter (Table 2.1, Figure 4.3) |
| Code | Courier New 10 pt, single spaced |
| Footnotes | 10 pt |
| Single spacing for | Captions, tables, code, footnotes, TOC and lists, reference entries, appendix forms |
| Margins | Top 1 in, bottom 1 in, left 1.25 in, right 1 in |
| Page numbers | None on title page; lower-case Roman before Chapter 1; Arabic from Chapter 1; right aligned |
| Headers | Report title on odd pages, chapter title on even pages, none on a chapter's first page |
| Citations | IEEE numbered, [1], in order of first citation |
| Equations | Numbered (3.1) at the right margin, every symbol defined |
| Submission | Searchable PDF + editable DOCX, named with group ID, course and year |

Naming suggestion: `FYP1_<GroupID>_HandwrittenAmharicOCR_2026.docx` and `.pdf`.
