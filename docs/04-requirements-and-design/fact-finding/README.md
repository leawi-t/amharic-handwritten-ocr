# Fact finding

The proposal lists observation, interviews or short questionnaires, and
analysis of existing applications.

## Before collecting anything from people

Questionnaires and interviews count as **human participants**. The ethical
screening checklist (`../../compliance/ethical-screening.md`) must be completed,
and the project needs **written approval from the advisor and the Committee**
before data collection starts (guideline 15.4, Appendix M).

- Use an informed-consent statement at the top of every questionnaire.
- Collect only what you need. Avoid names and phone numbers unless essential.
- **Do not commit raw responses** that contain personal data to this
  repository. Commit only an anonymised summary.
- Do not paste raw responses into public AI tools (Section 15.3).
